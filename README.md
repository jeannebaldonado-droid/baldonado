# Socket.IO Messaging App

Simple chat UI and Node.js server using Socket.IO.

Quick start

1. Install dependencies:

```bash
npm install
```

2. Start the server:

```bash
npm start
```

3. Open http://localhost:3000 in your browser, enter a name and press Connect.

Files

- [index.html](index.html) — UI and CSS
- [client.js](client.js) — client-side Socket.IO logic
- [server.js](server.js) — Express + Socket.IO server
